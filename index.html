YOKO · PROJECT DEEP DIVE

Yoko: Robot + Companion Application

Yoko combines a physical companion robot with a software interaction layer. The system is designed to connect natural-language interaction with physical robotic behaviour.

The Robot

The robotic platform uses an ESP32-based control system, servo-driven movement and an expressive display interface. The physical system provides the foundation for movement, expressions and interaction.

Companion Application

The companion application acts as an interaction layer between the user, AI system and robot. It can be used to communicate commands and translate higher-level instructions into structured actions.

Natural Language → Robot Action

A key research direction is converting natural-language instructions into structured commands that the robot can interpret and execute.
